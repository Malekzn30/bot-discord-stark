# 📚 Guides d'utilisation

Ce dossier contient tous les guides pour utiliser le bot :

## 📖 Guides disponibles

### 🎫 TICKETS_GUIDE.md
**Système complet de tickets Discord**
- Configuration par le propriétaire
- Utilisation par les membres
- Commandes : `+ticket setup`, `+ticket setup categories`, etc.
- Personnalisation : catégories, questionnaires, messages

### 🎤 VOICE_GUIDE.md  
**Gestion vocale avancée**
- Commandes de déplacement : `+moove`, `+server`, `+split`
- Auto-balance : `+autobalance`, `+smartbalance`
- Rotations et jeux : `+shuffle`, `+spin`, `+russianroulette`
- Contrôle vocal : `+muteall`, `+lockvoice`, etc.

## 🎯 Comment utiliser les guides

1. **Lis le guide complet** pour comprendre le système
2. **Cherche la commande spécifique** dans la table des matières
3. **Copie-colle les exemples** pour t'entraîner
4. **Adapte à ton serveur** avec tes IDs et rôles

## 💡 Conseils

- **ID de catégorie** : Clic droit > Copier l'ID (mode dév activé)
- **Rôles requis** : Vérifie que tu as le rôle autorisé
- **Permissions bot** : Le bot doit avoir les permissions nécessaires
